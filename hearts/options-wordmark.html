Claude Hearts: visual choices for Shawn

Our own lettering for "Hearts"

Six fonts for the title next to the logo, each drawn as shapes like the card faces, so it looks the same on every phone. Only the title changes. Each option shows the lettering large, then the top of her screen at real size. The title stays the same height as today's; the size can be a separate choice once you have picked a font.

Screen readers: the drawing is hidden from them, and the heading still holds the words, so VoiceOver reads "Hearts" (or "Corazones" in Spanish) exactly as it does now. One thing to know: the drawing says "Hearts" in every language, like the name under the Home Screen icon; today's title says "Corazones" in Spanish.
